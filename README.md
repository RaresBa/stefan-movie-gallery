# Stefan Movie Gallery

This project was created by **Baiasu Stefan Rares** for **Assignment 03**
of the **Information System Development** course.

## Overview

Stefan Movie Gallery is a web application for keeping track of movies
you want to watch and movies you have already watched. Users can add movies with their title, poster image, genre, duration,
and information about where to watch them. The gallery organizes movies
into two tables: **To be watched** and **Watched**.

## Features

- Add movies with a title, genre, duration in minutes, and viewing platform.
- View separate tables for movies to be watched and movies already watched.
- Mark a movie as watched or move it back to the watchlist.
- Delete movies through a confirmation dialog.
- Store movie information and watched status in a database.

## Technologies

- **Python and Flask** — backend application and request handling.
- **HTML, CSS, and JavaScript** — page structure, styling, and interactions.
- **Flask-SQLAlchemy** — database models and operations.
- **SQLite** — database for local development.
- **PostgreSQL through Neon** — database configured for production.
- **Vercel** — deployment platform.
